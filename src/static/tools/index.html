Tools — ファイル変換

ファイルのちょっとした加工

PDFをまとめたり、必要なページだけ取り出したり、写真を軽い webp にしたりできます。

ファイルはどこにも送信されません。すべてあなたのブラウザの中だけで処理されます。インターネットにつながっていなくても（一度ページを開いた後なら）動きます。
