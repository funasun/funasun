動画編集切る・つなぐ

動画を読み込んで、要る部分だけ切り出し、順番に並べて1本のMP4にします。 処理はこの端末の中だけで行い、どこにも送りません。 作り直さずに並べ直すだけなので、画質はそのまま・書き出しは一瞬です。

1. 動画を入れる

対応: MP4 / MOV（iPhone撮影・画面収録・このサイトで共有した動画）。THETA などの360°動画は、向きを決めて普通の動画に切り出せます。

2. 並べる （↑↓で順番、クリップを押すと下で切れます）

    全体の長さ: 0.0秒

    3. 切る

    0.00秒

    3.5 効果をつける

    ここを使うと動画を作り直すので、書き出しに時間がかかります（そのかわり文字入れや正確なカットができます）。 何も設定しなければ、今までどおり一瞬・無劣化で書き出します。

    3.7 360°の視点

    このクリップは全天球（360°）の動画です。ドラッグで向きを決めると、その向きで切り出した普通の動画になります。 ピンチ／ホイールで画角（ズーム）。書き出しの比率は下の「4. 書き出す」で選べます（縦・横どちらも）。

    水平を直す：横を向くと斜めになるときは、元の映像の「上」がずれています。 つまみを左右に動かすと、いま見ている向きを中心に絵が回ります（iPhone の写真アプリの傾き直しと同じ）。 前を向いて水平にし、横を向いてもう一度合わせると決まります。

    0°
    いま動かしているのは「始まり」

    4. 書き出す

    効果を使わないときは、動画を作り直さずに並べ替えるだけなので一瞬・無劣化です。 そのかわり開始位置が「区切りの良い場所」に数秒単位で丸まります。 テロップなどの効果を使うと作り直しになり、時間はかかりますが1コマ単位で正確に切れます。
