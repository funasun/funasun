Tools — ファイル変換

ファイルのちょっとした加工

PDFをまとめる・ばらす・並べ替える、画像とPDFを行き来する、画像を軽くする。よく要る手当てをひと通り。

ファイルはどこにも送信されません。すべてあなたのブラウザの中だけで処理されます。インターネットにつながっていなくても（一度ページを開いた後なら）動きます。

PDFをまとめる

複数のPDFを、上から順に1つのファイルにつなげます。順番は矢印で入れ替えられます。

ここにドラッグ、またはクリックして選択

PDFファイルのみ

共有URLを貼り付けて取り込む

このサイトの「ファイルを送る」で共有したURLを、1行に1つずつ貼り付けてください。ダウンロードしなくてもそのまま取り込めます。
（よそのサイトのURLは、その相手先が外からの読み取りを許していないため取り込めません。合言葉つきのファイルも一度ダウンロードが必要です。）
