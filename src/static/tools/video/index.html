動画編集切る・つなぐ

動画を読み込んで、要る部分だけ切り出し、順番に並べて1本のMP4にします。 処理はこの端末の中だけで行い、どこにも送りません。 作り直さずに並べ直すだけなので、画質はそのまま・書き出しは一瞬です。

1. 動画を入れる

対応: MP4 / MOV（iPhone撮影・画面収録・このサイトで共有した動画）。

2. 並べる （↑↓で順番、クリップを押すと下で切れます）

    全体の長さ: 0.0秒

    3. 切る

    0.00秒

    4. 書き出す

    開始位置は動画の「区切りの良い場所（キーフレーム）」に合わせて数秒単位で丸まります。 作り直しをしないための仕組みで、そのかわり画質が一切落ちません。
